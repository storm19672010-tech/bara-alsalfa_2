# برّا السالفة 🕵️

لعبة جماعية أونلاين: الكل يعرف «السالفة» إلا واحد. اكشفوه قبل ما يكشفكم!
الواجهة عربية بالكامل، وكل لاعب يدخل من جهازه كضيف بالاسم فقط.

## التشغيل على جهازك

```bash
node server.js
```

افتح http://localhost:3000 . (يحتاج Node.js 18 أو أحدث، بدون تثبيت أي مكتبات.)
للعب مع أصحابك على نفس الشبكة، افتح `http://<عنوان-جهازك>:3000` من أجهزتهم.

## نشره على الإنترنت (عشان أي حد يدخل برابط)

الموقع يحتاج سيرفر Node شغّال (مو استضافة ملفات ثابتة مثل GitHub Pages).
أسهل الطرق (فيها خطط مجانية):

- **Render.com**: New → Web Service → اربط المشروع من GitHub → Build Command: فاضي أو `npm install` → Start Command: `node server.js`.
- **Railway** / **Fly.io** / **Glitch** / **Replit**: ارفع المجلد كما هو، الأمر `npm start`.

المنفذ يُقرأ تلقائياً من متغير `PORT`.

ملاحظات:
- الغرف محفوظة بالذاكرة، فلو السيرفر أعاد التشغيل أو نام (بعض الخطط المجانية تنيّم السيرفر) تضيع الغرف الحالية.
- شغّله على نسخة واحدة فقط (instance واحدة).

## طريقة اللعب

1. المضيف ينشئ غرفة → يحصل على كود من 5 أرقام ورابط دعوة.
2. الباقي يدخلون بالكود أو الرابط ويكتبون أسماءهم (3 – 12 لاعب).
3. المضيف يختار الموضوع (أو عشوائي) ويبدأ.
4. كل لاعب يقلب بطاقته: جوا السالفة ← تظهر السالفة، برا السالفة ← «أنت برا السالفة».
5. أسئلة بالدور («فلان اسأل فلان») ثم أسئلة حرة، شفهياً بينكم. **ما في أي مؤقتات**، والمضيف وحده ينقل للسؤال التالي ويبدأ التصويت.
6. تصويت على مين برا السالفة ← كشف الاسم ← اللي برا يخمّن السالفة من خيارات.
7. السكور: صوّتت صح **+100**، اللي برا خمّن صح **+100**.
8. أثناء الأسئلة: زر 🔄 لتصويت تغيير السالفة (يلزم موافقة الكل)، وزر 🚩 لتصويت خصم **−10** من اللاعب اللي سؤاله كشف السالفة (يلزم موافقة الكل).
9. اللي يدخل والجولة شغّالة يستنى بغرفة الانتظار للجولة الجاية. اللي يطلع يظهر للكل مباشرة وينلغى دوره. ما يصير اسمين متشابهين. لوحة الترتيب ظاهرة طول الوقت.
10. «جاهز لجولة أخرى» (السكور محفوظ) أو «خروج من الغرفة».

## الصور ومعلومات الشخصيات

- كل سالفة تظهر معها صورة (تُجلب من ويكيبيديا من متصفح اللاعب، وإذا فشلت تظهر إيموجي الموضوع). اللي برا السالفة ما يشوفها.
- شخصيات الأنمي تظهر معها اسم الأنمي وتفصيلة صغيرة (`ANIME_INFO` في `topics.js`).
- خصم «السؤال الكاشف» ينعكس فوراً على لوحة الترتيب بدون انتظار نهاية الجولة.

## التعديل

- المواضيع والكلمات: `topics.js`
- النقاط وأعداد اللاعبين: الثوابت أعلى `server.js`
- التصميم والواجهة: `public/index.html`
- اختبار آلي لسير اللعبة كاملة: `node test.js`
